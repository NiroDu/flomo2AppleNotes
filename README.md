# flomo2notes

flomo笔记转移到苹果备忘录的方案，简单直接。

### 安装依赖

```
npm run install
```

### 运行

```
npm run start
```

运行后会提示输入 flomo 导出的完整文件夹（包含 HTML 和 `file/` 附件目录）所在的路径，例如：

```
> /Users/du/Downloads/flomo@xxx-20260531
```

脚本会自动查找该目录下唯一的 HTML 文件，拆解后输出到源目录下的 `output/` 子目录，原目录内容保持不变。

即可转换成功，然后选择“导入至备忘录”即可。

### 功能特点

- 自动拆解每条 MEMO 为独立的 HTML 文件
- 文件命名格式：`日期时间_内容第一行.html`，便于辨认
- 保留加粗（`<strong>`）、高亮（`<mark>`）、下划线（`<u>`）等格式
- 保留有序/无序列表结构
- 图片附件自动复制到 output 目录，使用绝对路径引用
- 音频录音保留转录文本展示
- 超链接保持原样
- `#标签` 保留在内容中
- 时间信息移至条目末尾展示
- **每个 HTML 文件的修改时间设为对应笔记的原始创建时间**，导入 Apple Notes 后即为正确的创建时间

### Apple Notes 已知限制

- ⚠️ `<mark>` 高亮标记导入后不生效（Apple Notes 不支持）
- ⚠️ `#标签` 导入后需手动点击激活为 Apple Notes 标签
- ⚠️ 音频文件无法通过 HTML 导入到 Apple Notes
